# 精灵图处理工具

一个**纯本地、零依赖**的精灵图（Sprite Sheet）处理工具。全部逻辑用原生 HTML + CSS + JavaScript 实现，
不需要安装任何东西，也不需要起服务器 —— **直接双击 `index.html` 就能用**。

> 说明：本工具由 AI 编程助手生成，属于**非专业、个人自用**的小工具，主要用途是给游戏
> **铁锈战争（Rusted Warfare）** 做模组图像处理与 GIF 制作。

自带一套由 AI 编程助手编写的 GIF 编解码器（LZW + 中位切分量化），因此 GIF 的读取与导出都不依赖任何第三方库，
离线、`file://` 环境下同样可用。

---

## 快速开始

双击 `index.html`。就这样。

- 浏览器建议：Chrome / Edge / Firefox 等现代浏览器（需要支持 Canvas 2D 与 `Uint8ClampedArray`）。
- 无需 Node、Python、npm，无需联网。
- 所有处理都在浏览器内存里完成，图片不会上传到任何地方。

## 功能一：✂️ 裁剪工具

把一张图里**真正有内容的部分**自动框出来，导出成紧凑的 PNG。

- **拖拽或选择**一张/多张图片，左侧列表会列出全部待处理图。
- **自动检测边界**，两种模式：
  - `透明通道 (Alpha)` —— 找出四边最外侧「不透明」的像素（默认，适合带透明底的 PNG）。
  - `背景色差分 (取四角)` —— 以四角像素的平均色作为背景色，容差内的像素视为背景（适合纯色底 JPG/PNG）。
  - 两个阈值滑杆：`Alpha 阈值`（1–254）与 `颜色容差`（0–255）。
- **手动微调**：左 / 上 / 右 / 下四个方向各有 ± 按钮和数字输入框，**正数 = 向外扩展，负数 = 向内收缩**（单位像素）。
  预览画布上会用遮罩标出保留区域。
- **`重新检测`** 恢复自动结果，**`重置调整`** 把偏移清零。
- **导出**：`导出当前 PNG` 输出当前这一张（文件名加 `_crop` 后缀）；
  `导出全部 (ZIP)` 把所有图各自裁剪后打包成一个 ZIP 下载。
- **裁剪结果不会自动保存**，必须点导出。

> ZIP 由内置的 store 模式打包器（含 CRC32）现场生成，不需要 JSZip 之类的库。

## 功能二：🧩 拼接工具

分「静态图像拼接」和「GIF 帧编辑」两个子页。

### 静态图像拼接

- 拖入多张 PNG / JPG（帧顺序默认 = 上传顺序，可按名称升序 / 降序 / 自然序排序，也可在左侧列表**拖动排序**）。
- **图像宽 / 高**自动取所有图的最大宽高（不足的会自动留白对齐）。
- **帧数**留空 = 自动等于图片数量；手动填写后按下方说明处理。
- **行 / 列**：默认自动排成 `1 行 × N 列`，改动任一参数，另一个会自动重算。
- **镜像**：勾选后帧数翻倍，多出来的后半段是前半段水平翻转的帧（常用于做「向左走 / 向右走」这类动画）。
- 右侧两个预览：**合成图预览**（即最终的精灵表）和**动画预览**（可播放，看逐帧效果）。
- 导出：
  - `导出 PNG` —— 整张精灵表。
  - `导出 GIF` —— 把每帧按设定的 `GIF 帧延时` 做成动画（镜像开启时自动加倍帧数）。
- 会自动识别只有 1 帧的情况并给出提示（单帧没有动画可言）。

**关于「帧数」的语义 —— 拼接后拆分：**
当填写的帧数与实际上传的图片数量**不一致**时，工具会先把所有图片横向拼成一条长图，
再把这根长条**均分成 N 份**作为最终帧（每份宽度 = 总宽 ÷ N）。
这样做的好处是可以把「本来连在一起的长图」直接切成想要的帧数，而不用先在别的工具里切图。

### GIF 帧编辑

- 拖入一个 GIF，工具会用内置解码器解析出全部帧（含透明通道、disposal、interlace、循环信息）。
- 左侧帧列表：**可拖动排序**，每项有上移 / 下移 / 删除按钮；下方有**逐帧延时**输入框。
- 中间参数区：
  - `插入图片帧` —— 从文件选图片，追加为新的帧（会缩放到帧尺寸）。
  - `全部帧设为 __ ms + 应用` —— 一键把所有帧的跳转时间改成同一个值。
  - `行 / 列 / 镜像` —— 控制合成图排布，镜像会让帧数翻倍。
- 预览：**合成图预览**（所有帧拼成的精灵表）与 **GIF 预览**（带真实延时的动画播放）。
- 导出：`导出 PNG`（精灵表）/ `导出 GIF`（按当前帧顺序与逐帧延时重新编码）。

## 功能三：🔎 自动裁剪（网格拆分精灵表）

把**一张精灵表原图**按网格自动拆成独立的一帧帧精灵图。

- 拖入 1 张图片，左侧列表会列出拆出来的每一个单元格（带缩略图、`第 N 帧`、`(x, y) 尺寸`）。
- 两种拆分方式（顶部「拆分方式」切换）：
  - **按单元格尺寸**：填 `单元格宽 / 单元格高` → 工具自动算出 `列数 = ⌊图宽 ÷ 单元格宽⌋`、`行数 = ⌊图高 ÷ 单元格高⌋`。
  - **按行列数**：填 `行数 / 列数` → 工具自动算出每格 `单元格宽 = ⌊图宽 ÷ 列数⌋`、`单元格高 = ⌊图高 ÷ 行数⌋`。
- 可选 `起始 X / 起始 Y`（网格起点偏移）与 `间距 X / 间距 Y`（单元格之间的留白），
  方便处理带边距 / 内边距的精灵表。
- 预览画布上会用青色描出每一个单元格并标上序号；点列表里的某帧会高亮对应格子。
- 导出：
  - 每个单元格右侧有 `导出` 按钮 → 单独导出该帧 PNG（文件名 `前缀_序号.png`）。
  - `导出全部 (ZIP)` → 把所有帧打包成 ZIP 一次下载。
  - `文件名前缀` 留空时默认用原图文件名。
- **只生成能完整落在图内的单元格**（边缘放不下的残格会被跳过），保证每帧尺寸一致、可直接拼回去。

## 技术说明

### GIF 编解码器（`gif-codec.js`）

- `GifCodec.decodeGif(buffer)` → `{ width, height, frames: [{ data: Uint8ClampedArray(RGBA), delay }] }`
- `GifCodec.encodeGif(frames, width, height, { loop })` → `Uint8Array`（GIF89a，带透明通道）

实现要点：

- 解码：支持 LZW、透明色索引、`disposal` 各种处置方式、`interlace` 隔行扫描、Netscape 循环扩展块。
- 编码：LZW 压缩 + **中位切分（median cut）量化**（当颜色数超过 255 时自动降色，做透明键控）。
- 编解码两侧的**码长增长时机必须严格对齐**（在词典写入前判断扩容），否则大图会出现乱码 —— 这是本工具踩过的坑。
- 该文件同时兼容浏览器（挂 `window.GifCodec`）与 Node（`module.exports`），方便做自动化测试。

### 其他

- 图片加载统一走 `Blob → URL.createObjectURL → <img>`，全部在内存中完成。
- 导出走 `Blob` + 临时 `<a download>`。
- 拖拽排序用原生 HTML5 Drag & Drop。
